# Third-party code

Navigation components under `instance_nav/` and the evaluation entry points
under `application/evaluation/` were adapted from the VLMaps codebase. Source
files carry an attribution header. The original MIT license text is preserved
in [VLMaps-LICENSE](VLMaps-LICENSE).

The repository also includes research-specific changes for fine-grained
instance matching, color descriptions, and multi-floor navigation. The MIT
notice applies to the VLMaps-derived portions; it does not imply that the
entire repository originated with VLMaps.
